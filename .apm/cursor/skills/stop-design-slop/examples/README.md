# Examples

These are deliberately small, dependency-free examples. Open the HTML files in a browser and resize the window.

- `card-soup-before.html` — repeated rounded containers, equal salience, generic icon tiles.
- `structural-hierarchy-after.html` — same conceptual content organized by typography, dividers, alignment, and one meaningful bounded region.
- `generic-hero-before.html` — stereotyped AI/SaaS hero composition.
- `product-led-hero-after.html` — product artifact and task lead the composition.
- `dashboard-before.html` — KPI tiles and cards dominate an operational screen.
- `dashboard-after.html` — primary work object dominates; metrics become contextual signals.

The examples are not "the correct style". They demonstrate how to move from decorative grouping toward semantic structure.
