# Pattern catalog: symptoms, diagnosis, remedies, exceptions

## 1. Card soup

**Symptoms**
- Every heading/body cluster has its own rounded box.
- Cards contain cards whose only difference is padding/background.
- Repeated shadow/border/radius creates many equally salient surfaces.

**Diagnosis**
Excessive common-region grouping. The interface is encoding weak or nonexistent semantic boundaries as strong visual boundaries.

**Remedies**
- Remove outer or inner containers.
- Re-group with proximity and alignment.
- Use section rules, indentation, or background planes.
- Let one primary workspace surface contain several typographic sections.

**Valid exception**
A card is a selectable record, draggable object, independently actionable item, or a unit that needs to preserve grouping responsively.

## 2. Radius inflation

**Symptoms**
- 16–24px radius on every component.
- Screenshots, data tables, nav, dialogs, inputs, badges all share one soft geometry.

**Diagnosis**
Shape token used as generic polish rather than semantic/brand system.

**Remedies**
- Define 2–4 shape roles (e.g. dense surface, control, prominent surface, capsule).
- Reduce radius on high-density/structural objects.
- Reserve capsule geometry for compact token-like components.

## 3. Purple/cyan AI landing page

**Symptoms**
- dark navy backdrop;
- blurred violet/cyan blobs;
- gradient headline;
- glass panels;
- neon border/shadow.

**Diagnosis**
Trend/default-style convergence plus effect stacking.

**Remedies**
- remove all effects first;
- establish composition and product artifact;
- reintroduce at most one brand-supported motif;
- choose color from brand/content semantics rather than "AI" category cliché.

## 4. SaaS hero generator

**Symptoms**
Eyebrow pill → centered H1 → muted subtitle → two CTAs → floating screenshot.

**Diagnosis**
Template convergence. Page structure is determined before content/task.

**Remedies**
- identify the strongest product proof or action;
- let real output/data/search/workspace lead;
- choose alignment from reading/content needs;
- demote or eliminate generic marketing chrome.

## 5. Three-card features

**Symptoms**
Three equal columns, each icon + title + two lines.

**Diagnosis**
Grid-driven information architecture; artificial equality.

**Remedies**
- rank features;
- demonstrate the dominant feature with a real artifact;
- show workflow/sequence if causal;
- use comparison if alternatives matter;
- use a compact list if scanning matters.

## 6. Icon badge wallpaper

**Symptoms**
Every heading has a generic line icon in a colored rounded square.

**Diagnosis**
Decorative iconification; repeated salience without information.

**Remedies**
- delete icons and see whether comprehension changes;
- keep icons only for recognition/state/action;
- use domain-specific symbology where justified.

## 7. KPI strip

**Symptoms**
Four statistic tiles at top of any dashboard.

**Diagnosis**
Dashboard cargo cult. Salience is inherited from template convention rather than decision value.

**Remedies**
- ask which values trigger action;
- promote only system-state/decision-critical metrics;
- embed context next to chart/table/object it explains;
- show trends or thresholds where change matters more than absolute value.

## 8. Premium minimalism

**Symptoms**
Huge title, enormous margins, one tiny content block, low-contrast gray, sparse controls.

**Diagnosis**
Showroom optimization over operational efficiency.

**Remedies**
- measure what users need to compare simultaneously;
- increase content density without increasing feature competition;
- use clear rows/columns and typography;
- keep whitespace at major transitions rather than everywhere.

## 9. Component library identity leak

**Symptoms**
The page looks like a shadcn/Radix/Material starter before the logo is visible.

**Diagnosis**
Component-library fingerprinting.

**Remedies**
- preserve behavior/accessibility;
- alter macro composition first;
- establish product-specific type, density, shape, chart, and surface rules;
- customize interaction states, not only colors.

## 10. Fake product proof

**Symptoms**
Fabricated chart, dashboard, map, customer-logo strip, activity feed, or metric.

**Diagnosis**
Decorative product imagery / fictive evidence.

**Remedies**
- use authentic outputs;
- use clearly labeled sample data when real data is unavailable;
- prefer a schematic explaining real functionality over a fake screenshot.

## 11. Uniform salience

**Symptoms**
All sections have same padding, border, heading size, and contrast.

**Diagnosis**
Weak visual hierarchy.

**Remedies**
- assign dominant/supporting/quiet/background roles;
- remove chrome from quiet elements;
- make one object measurably larger or more central;
- use contrast sparingly.

## 12. Mechanical spacing

**Symptoms**
Every gap is the same token regardless of relationship.

**Diagnosis**
Token compliance mistaken for composition.

**Remedies**
- define within-group, between-group, and section-transition spacing roles;
- keep dense local relationships tight;
- use large whitespace selectively to mark major conceptual breaks.
