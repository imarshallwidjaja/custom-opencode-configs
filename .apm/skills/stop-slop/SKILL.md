# Stop Slop

Remove filler, formulaic structures, and mechanical cadence from prose while preserving meaning, facts, and tone.

## Core Rules

1. **Cut filler phrases.** Remove throat-clearing openers and emphasis crutches. See [references/phrases.md](references/phrases.md).
2. **Break formulaic structures.** Avoid LinkedIn cadence, antithesis, stacked negation, dramatic fragmentation, and rhetorical setups. See [references/structures.md](references/structures.md). Flattening the rhythm is not enough if the contrast frame remains.
3. **Vary rhythm without reshaping meaning.** Mix sentence lengths and paragraph endings, but never add, merge, or remove list items for cadence. Retain every semantically distinct item.
4. **Trust readers.** State facts directly. Preserve meaningful uncertainty, scope, and qualifiers. Remove empty hedging that only softens the point without adding information.
5. **Cut quotables.** If it sounds like a pull-quote, rewrite it.

## Quick Checks

- Three consecutive sentences match length? Break one.
- Paragraph ends with punchy one-liner? Vary it.
- One sentence per paragraph for emphasis? Join related sentences.
- "It's not X, and it's not Y, but Z"? State Z. Keep X and Y only if the reader was already considering them.
- "The best X don't Y. They Z."? State Z, then Y only if it is a live alternative.
- "Stop X. Start Y."? State the action.
- Em-dash before a reveal? Remove it.
- Explaining a metaphor? Trust it to land.
- "And that's okay."? Delete it unless the reader asked for permission.
